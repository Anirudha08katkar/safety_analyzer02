# Smart Safety Analyzer 

Smart Safety Analyzer is a beginner-friendly cybersecurity project that analyzes different types of user input and provides a basic safety/risk assessment.

## Features

### 1. Password Safety Analyzer
Analyzes a password based on:
- Length
- Uppercase letters
- Lowercase letters
- Digits
- Special characters

It generates a password strength score and classifies the password as weak, medium, strong, or very strong.

### 2. Spam Message Safety Analyzer
Analyzes a message for suspicious words and patterns such as:
- Urgent requests
- Prize/lottery-related words
- OTP/password/bank/account-related words

It generates a spam risk score and classifies the message as low, medium, or high risk.

### 3. URL Safety Analyzer
Performs basic checks on a URL, including:
- URL length
- HTTP usage

It then provides a basic safety assessment.
